# אתר בית הכנסת הכיפה, באר שבע

אתר סטטי, מתארח ב-GitHub Pages בכתובת hakipabs.org (גם www מפנה לשם).

## עדכון שבועי: מעלים את הדף השבועי (PDF) וזהו
1. נכנסים לתיקייה `weekly/` → **Add file** → **Upload files** (עובד גם מהטלפון).
2. גוררים את ה-PDF של השבוע (כל שם קובץ, רצוי שם הפרשה באנגלית, למשל `lech-lecha.pdf`) → **Commit changes**.
3. תוך כדקה אוטומציה קוראת מה-PDF את הפרשה, הדלקת נרות, צאת השבת, זמני התפילות, מנחה של חול וזמני היום,
   מעדכנת את `data/shabbat.json`, ושומרת עותק כ-`weekly/latest.pdf` (הקישור "הדף השבועי המלא" באתר).
4. עוד כדקה והאתר מעודכן.

אם משהו לא נקרא נכון, אפשר לתקן ידנית ב-`data/shabbat.json` (עיפרון → שינוי → Commit).
רשימת השיעורים בשבת לא מתעדכנת מה-PDF; היא קבועה ב-`index.html`.

## עדכון תוכן אחר
`index.html`: מניינים, שיעורים, תלמוד תורה, הוועד, תרומות, קשר.
`images/`: תמונות.

## אירוע חד-פעמי (סעודה, שיעור מיוחד, הרצאה)
עורכים את `data/events.json` ומוסיפים פריט:
```json
{ "title": "שם האירוע", "date": "2026-10-17", "when": "מוצאי שבת פרשת נח, 20:30",
  "place": "בית המדרש", "text": "משפט או שניים", "poster": "images/events/שם-הקובץ.jpg" }
```
את הפוסטר מעלים ל-`images/events/`. האירוע מופיע בבלוק "אירועים קרובים" ונעלם לבד למחרת ה-`date`.

## פעם בשנה: לוח הדלקת נרות שנתי
מעלים את ה-PDF השנתי ל-`yearly/` (אותו תהליך כמו השבועי: Add file → Upload files → Commit).
האוטומציה כותבת את כל השורות ל-`data/yearly.json`, והלוח המתקפל תחת "זמני תפילה" מתעדכן. השבת הקרובה מודגשת לפי הדף השבועי.

## הוועד
`data/board.json`: תפקיד, שם, טלפון (בפורמט 05X-XXX-XXXX). עיפרון → שינוי → Commit. הדף מציג מהקובץ עם קישורי חיוג.

## שיעורים קבועים
`data/shiurim.json`: `daily` (כל יום) ו-`weekly` (לפי יום, עם `items`). שדות: title, when, who, place, ואופציונלי tag, link, days. עריכה → Commit.

## מזל טוב / כוס תנחומים
נקראים אוטומטית מהדף השבועי (הפריטים שמתחילים ב-* אחרי הכותרת) ומוצגים כפס מתחת לזמני השבת. כשאין פריטים הפס לא מופיע. תיקון ידני: `data/shabbat.json`, שדות `mazal_tov` ו-`nichumim`.

## אוטומציה מלאה: מהמייל לאתר (Apps Script)
`tools/gmail-to-github.gs` רץ בתוך Gmail של הוועד פעם בשעה: מייל חדש מ-hakipa.zmanim@gmail.com עם PDF → הקובץ נדחף ל-`weekly/` → ה-Action מעדכן את האתר. הוראות ההתקנה בראש הקובץ. דורש טוקן גיטהאב מצומצם לריפו הזה (Contents: Read and write) ב-Script Properties בשם `GITHUB_TOKEN`.

## לוחות זמנים לחגים (ימים נוראים, סוכות, פסח, פורים, יום העצמאות)
מעלים את ה-PDF ל-`holidays/` (ידנית, או אוטומטית מהמייל: כל PDF מהשולח של הזמנים שהנושא שלו אינו "זמני השבוע").
האוטומציה מציירת את הדף כתמונה ומוסיפה אותו ל-`data/holidays.json`; באתר הוא מופיע בבלוק "לוחות זמנים לחגים" מתחת לזמני השבת,
למשך 45 יום (או עד תאריך בשדה `until`). מחיקת ה-PDF מסירה אותו. הכותרת נלקחת מכותרת הדף; אפשר לתקן ב-JSON.

## דוח במייל אחרי כל ריצה
הסקריפט שולח ל-vaad@hakipabs.org מייל אחרי כל העלאה אוטומטית: מה עלה, מה האתר מציג (פרשה, נרות, צאת שבת, מנחה, תפילת ילדים, מזל טוב),
אילו שדות לא נקראו, וקישורים לתיקון ידני. נושא שמתחיל ב-✅ = תקין; ⚠️ = דרושה בדיקה; ❌ = ההעלאה נכשלה.
