# אתר בית הכנסת הכיפה, באר שבע

אתר סטטי, מתארח ב-GitHub Pages בכתובת hakipabs.org (גם www מפנה לשם).

## עדכון שבועי: מעלים את הדף השבועי (PDF) וזהו
1. נכנסים לתיקייה `weekly/` → **Add file** → **Upload files** (עובד גם מהטלפון).
2. גוררים את ה-PDF של השבוע (כל שם קובץ, רצוי שם הפרשה באנגלית, למשל `lech-lecha.pdf`) → **Commit changes**.
3. תוך כדקה אוטומציה קוראת מה-PDF את הפרשה, הדלקת נרות, צאת השבת, זמני התפילות, מנחה של חול וזמני היום,
   מעדכנת את `data/shabbat.json`, ושומרת עותק כ-`weekly/latest.pdf` (הקישור "הדף השבועי המלא" באתר).
4. עוד כדקה והאתר מעודכן.

אם משהו לא נקרא נכון, אפשר לתקן ידנית ב-`data/shabbat.json` (עיפרון → שינוי → Commit).
רשימת השיעורים בשבת לא מתעדכנת מה-PDF; היא קבועה ב-`index.html`.

## עדכון תוכן אחר
`index.html`: מניינים, שיעורים, תלמוד תורה, הוועד, תרומות, קשר.
`images/`: תמונות.

## אירוע חד-פעמי (סעודה, שיעור מיוחד, הרצאה)
עורכים את `data/events.json` ומוסיפים פריט:
```json
{ "title": "שם האירוע", "date": "2026-10-17", "when": "מוצאי שבת פרשת נח, 20:30",
  "place": "בית המדרש", "text": "משפט או שניים", "poster": "images/events/שם-הקובץ.jpg" }
```
את הפוסטר מעלים ל-`images/events/`. האירוע מופיע בבלוק "אירועים קרובים" ונעלם לבד למחרת ה-`date`.

## פעם בשנה: לוח הדלקת נרות שנתי
מעלים את ה-PDF השנתי ל-`yearly/` (אותו תהליך כמו השבועי: Add file → Upload files → Commit).
האוטומציה כותבת את כל השורות ל-`data/yearly.json`, והלוח המתקפל תחת "זמני תפילה" מתעדכן. השבת הקרובה מודגשת לפי הדף השבועי.

## הוועד
`data/board.json`: תפקיד, שם, טלפון (בפורמט 05X-XXX-XXXX). עיפרון → שינוי → Commit. הדף מציג מהקובץ עם קישורי חיוג.

## שיעורים קבועים
`data/shiurim.json`: `daily` (כל יום) ו-`weekly` (לפי יום, עם `items`). שדות: title, when, who, place, ואופציונלי tag, link, days. עריכה → Commit.

## מזל טוב / כוס תנחומים
נקראים אוטומטית מהדף השבועי (הפריטים שמתחילים ב-* אחרי הכותרת) ומוצגים כפס מתחת לזמני השבת. כשאין פריטים הפס לא מופיע. תיקון ידני: `data/shabbat.json`, שדות `mazal_tov` ו-`nichumim`.

## אוטומציה מלאה: מהמייל לאתר (Apps Script)
`tools/gmail-to-github.gs` רץ בתוך Gmail של הוועד פעם בשעה: מייל חדש מ-hakipa.zmanim@gmail.com עם PDF → הקובץ נדחף ל-`weekly/` → ה-Action מעדכן את האתר. הוראות ההתקנה בראש הקובץ. דורש טוקן גיטהאב מצומצם לריפו הזה (Contents: Read and write) ב-Script Properties בשם `GITHUB_TOKEN`.

## לוחות זמנים לחגים (ימים נוראים, סוכות, פסח, פורים, יום העצמאות)
מעלים את ה-PDF ל-`holidays/` (ידנית, או אוטומטית מהמייל: כל PDF מהשולח של הזמנים שהנושא שלו אינו "זמני השבוע").
האוטומציה מציירת את הדף כתמונה ומוסיפה אותו ל-`data/holidays.json`; באתר הוא מופיע בבלוק "לוחות זמנים לחגים" מתחת לזמני השבת,
למשך 45 יום (או עד תאריך בשדה `until`). מחיקת ה-PDF מסירה אותו. הכותרת נלקחת מכותרת הדף; אפשר לתקן ב-JSON.

## דוח במייל אחרי כל ריצה
הסקריפט שולח ל-vaad@hakipabs.org מייל אחרי כל העלאה אוטומטית: מה עלה, מה האתר מציג (פרשה, נרות, צאת שבת, מנחה, תפילת ילדים, מזל טוב),
אילו שדות לא נקראו, וקישורים לתיקון ידני. נושא שמתחיל ב-✅ = תקין; ⚠️ = דרושה בדיקה; ❌ = ההעלאה נכשלה.

## אירועים מהמייל
מייל ל-vaad@ מאחד השולחים המורשים, עם פוסטר (JPG/PNG) מצורף:
- נושא `אירוע: מסיבת חתנים 17.10` → כרטיס "מסיבת חתנים" שמוצג עד 17.10. השורה הראשונה בגוף = "מתי ואיפה", השאר = טקסט. בלי תאריך בנושא: 14 יום.
- נושא שמכיל "אורייתא" (הפוסטר השבועי מהקבוצה) → אירוע של אותו יום, אוטומטית.
הרשומות נכתבות ל-`data/events.json`; תיקון או מחיקה שם.

## גלריית תמונות
כל תיקייה תחת `gallery/` היא אלבום (שם התיקייה = שם האלבום, מקפים הופכים לרווחים). מעלים תמונות מקור לתיקייה,
או שולחים מייל ל-vaad@ עם נושא `אלבום: מסיבת חתנים` והתמונות מצורפות (כמה מיילים עם אותו נושא מצטרפים לאותו אלבום).
האוטומציה מקטינה (1600px לצפייה, 480px לממוזער) וכותבת `data/gallery.json`; הדף `gallery.html` מציג אלבומים, רשת ותצוגה מוגדלת.
כותרת/תאריך/תמונת שער אפשר לקבוע בקובץ `album.json` בתוך התיקייה. מחיקת תיקייה מסירה אלבום.
תמונות של אנשים: לפרסם רק מה שהמצולמים מסכימים לו; בקשת הסרה מגיעה למייל הוועד מהקישור בתחתית הגלריה.

## מדידת תנועה
Cloudflare Web Analytics (בלי עוגיות). קטע הקוד בתחתית `index.html` ו-`gallery.html`. הדשבורד: dash.cloudflare.com → Web Analytics.

## ארכיון הקהילה (ההיסטוריה שלנו)
`archive.html` מציג ציר זמן של אוספים מתוך `archive/<אוסף>/`. בכל תיקייה: תמונות/PDF ו-`album.json`:
`title`, `period` (טקסט חופשי, למשל "שנות ה-60"), `year_sort` (מספר למיון), `description`, `contributor`, `approved` (true/false),
ו-`items` עם כיתוב ושנה לכל קובץ. **אוסף מתפרסם רק כש-`approved` הוא true.**
מייל ל-vaad@ עם נושא `ארכיון: <שם האוסף>` ותמונות/סריקות מצורפות יוצר את התיקייה כטיוטה (approved: false); חבר ועד מאשר, מוסיף כיתובים ותקופה, ו-Commit.
מסמכים (PDF) בארכיון: כל עמוד הופך לפריט עם קישור ל-PDF; שדה `text` ב-`album.json` מצרף תמלול מלא, שמוצג בכפתור "הטקסט המלא" בתצוגה המוגדלת.

## דבר תורה לפרשת השבוע (divrei-torah.html)

- **כל אחד** שולח ל-vaad@hakipabs.org, נושא `דבר תורה: <פרשה> / <שם הכותב>` (אפשר גם `/ כותרת` שלישית), הטקסט בגוף המייל (300 עד 600 מילים). PDF/Word מצורף נשמר ב-`divrei-torah/` ומקושר.
- **סינון:** המייל לא מתפרסם לבד. הסקריפט מסמן אותו `hakipa-dvar-torah-pending` ושולח לוועד "ממתין לאישור". חבר ועדה מהרשימה `CONFIG.dvarReviewers` מעביר אותו (Forward) ל-vaad@ או עונה עליו (Reply all) מתוך התיבה, ובריצה הבאה (עד שעה) הוא נכנס ל-`data/divrei-torah.json`. שם הכותב: מהנושא, או משורת `מאת:` בגוף, או משולח המייל המקורי.
- **באתר:** `divrei-torah.html` מציג את דברי התורה של פרשת השבוע (לפי הפרשה בדף השבועי) ואת כל הפרשות לפי קבוצות. בדף הבית מופיעה פסקת הפתיחה של הראשון, רק כשיש דבר תורה לפרשה הנוכחית.
- **תיקון/מחיקה:** לערוך את `data/divrei-torah.json` בגיטהאב (רשומה = פרשה, מחבר, כותרת, תאריך, פסקאות, קבצים). ה-`id` הוא עוגן הקישור. שדה אופציונלי `written` (טקסט חופשי, למשל "נכתב לפני מספר שנים") מוצג במקום התאריך, לדברי תורה ישנים שמוזנים ידנית.

## סרטונים (ערוץ היוטיוב)

- סרטונים לא נשמרים בגיטהאב (מגבלות גודל ורוחב פס). הם עולים לערוץ היוטיוב של בית הכנסת, https://www.youtube.com/@HakipaBS (חשבון vaad@), עדיף במצב "לא רשום".
- **באתר:** פריט וידאו באוסף ארכיון הוא שורה ב-`album.json` בלי קובץ: `"20-yovel.video": {"video": "<מזהה יוטיוב>", "caption": "...", "year": "..."}`. התמונה הממוזערת מגיעה מיוטיוב, והנגן נפתח בלייטבוקס.
- **במייל:** "ארכיון: <שם האוסף>" עם קישור יוטיוב בגוף (youtu.be/... או youtube.com/watch?v=...) מוסיף פריט וידאו לאוסף; השורה הראשונה בגוף שאינה קישור היא הכיתוב. אוסף חדש נכנס כטיוטה (`approved: false`) כרגיל.
