# אתר בית הכנסת הכיפה, באר שבע

אתר סטטי, מתארח ב-GitHub Pages בכתובת www.hakipabs.org.

## עדכון שבועי של זמני השבת
עורכים קובץ אחד בלבד: `data/shabbat.json`. לוחצים על הקובץ, על העיפרון, משנים את השעות, ו-Commit.
האתר מתעדכן תוך דקה. אין צורך לגעת ב-`index.html`.

## עדכון תוכן אחר
`index.html`: כל שאר הטקסטים (מניינים, שיעורים, תלמוד תורה, ועד, תרומות, קשר).
`images/`: תמונות.
